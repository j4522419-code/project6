Share files between your computer and your phone over Wi‑Fi. Nothing to install on the phone, because it just uses the browser.

![PairShare dashboard](https://raw.githubusercontent.com/j4522419-code/project6/v1.0.0/docs/host-dashboard.png)

## Download

Pick the file for **the computer** that will run PairShare. .NET is built in, so there's nothing else to install.

| Computer | Download |
|---|---|
| Windows (most PCs) | **PairShare-v1.0.0-win-x64.zip** |
| Windows on ARM (Surface Pro X, Copilot+ PCs) | PairShare-v1.0.0-win-arm64.zip |
| Mac with Apple silicon (M1 / M2 / M3 / M4) | PairShare-v1.0.0-osx-arm64.zip |
| Mac with Intel processor | PairShare-v1.0.0-osx-x64.zip |
| Linux (64-bit) | PairShare-v1.0.0-linux-x64.zip |

## Getting started

1. Unzip the download and run **PairShare** (on Windows, double-click `PairShare.exe`).
2. If Windows asks about the firewall, allow access on **private networks**.
3. The dashboard opens in your browser. It shows a **pair code**, a **link** and two **QR codes**.
4. On your phone (on the same Wi‑Fi):
   - scan **Quick pair** with the camera to connect instantly, **or**
   - scan **Scan to open** (or type the link), then enter the 6-digit pair code.
5. Send files from either side: tap **Send files** on the phone, or drag files onto the dashboard.

Files are kept in `Downloads/PairShare` on the computer.

## First-run warnings

PairShare isn't code-signed yet, so your computer may warn you the first time:

- **Windows** ("Windows protected your PC"): click **More info → Run anyway**.
- **macOS** ("can't be opened" / "unidentified developer"): open **System Settings → Privacy & Security** and click **Open Anyway**. Or, in Terminal, run `xattr -d com.apple.quarantine PairShare` in the unzipped folder.
- **Linux**: if needed, run `chmod +x PairShare` first.

## What's in 1.0.0

- Connect with a **link**, a **QR code + pair code**, or one-scan **Quick pair** for phones
- **Two-way file sharing** with live updates, progress bars and drag & drop
- Pair codes and quick-pair QR codes are **single-use** and expire after 5 minutes. Wrong codes are rate-limited.
- **Unpair** any device from the dashboard; phones can **Disconnect** themselves
- Works in light and dark mode, on phones, tablets and computers
- Command-line options: `--port`, `--dir`, `--address`, `--code-minutes`, `--max-upload-mb`, `--no-browser`

PairShare is meant for your home or office network. Traffic is plain HTTP, so it isn't encrypted.
Don't use it on Wi-Fi you don't trust.
